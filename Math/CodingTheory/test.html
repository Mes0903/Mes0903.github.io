關於奇數與偶數 d 的關係

假設 d 為奇數。當且僅當存在一個 binary (n+1,M,d+1)-code，才存在一個 binary (n,M,d)-code

關鍵：對 code C 執行 adding an overall parity check

x=x1x2⋯xn ⟶ x^={x1x2⋯xn0if w(x) is evenx1x2⋯xn1if w(x) is odd

推論：

  • 若 d 為奇數，則 A2(n+1,d+1)=A2(n,d)
  • 等價地，若 d 為偶數，則 A2(n,d)=A2(n−1,d−1)

Sphere in (Fq)n

對於 (Fq)n 中任一向量 u 與任一整數 r≥0，以 u 為中心、半徑為 r 的球，記為 S(u,r)，定義為

S(u,r)={v∈(Fq)n∣d(u,v)≤r}

若 d(C)≥2t+1，則以 C 的各個 codeword 為中心、半徑為 t 的球兩兩互斥（亦即它們沒有重疊）

The sphere-packing bound

在 (Fq)n 中半徑為 r 的球恰好包含

(n0)+(n1)(q−1)+(n2)(q−1)2+⋯+(nr)(q−1)r

個向量

sphere-packing 或 Hamming bound：
對於一個 q-ary (n,M,2t+1)-code，有

M{(n0)+(n1)(q−1)+⋯+(nt)(q−1)t}≤qn

Perfect codes

達到 sphere-packing bound 的 code 稱為 perfect code。因此，對於一個 perfect 的 t-error-correcting code，以各個 codeword 為中心、半徑為 t 的 M 個球會在 (Fq)n 上「填滿」整個空間而互不重疊

換句話說，在 (Fq)n 中的每個向量，與且僅與一個 codeword 的距離 ≤t

Trivial perfect codes：

  • 整個 (Fq)n
  • 當 n 為奇數時，長度為 n 的 binary repetition code{0 0 ⋯ 01 1 ⋯ 1
